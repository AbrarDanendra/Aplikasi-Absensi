📊 Integrasi Google Sheets & Drive

Sambungkan aplikasi ini ke Google Sheets & Google Drive Anda via Web App Google Apps Script.

💡 Langkah Singkat Memasang Backend:
  1. Buka file Code.gs di project ini.
  2. Buat Google Spreadsheet baru di Google Drive Anda.
  3. Buka Ekstensi > Apps Script, hapus kode lama, paste isi Code.gs.
  4. Jalankan fungsi setupDatabase() untuk membuat tabel otomatis.
  5. Klik Deploy > New deployment > Web app > Anyone.
  6. Salin URL Web App yang dihasilkan ke kotak di atas!
